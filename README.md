# memo-press

メモ帳で書いたブログの下書きを、WordPress（テーマ：JIN／クラシックエディタ）にそのまま貼り付けられる形に変換し、あわせて文章をチェックするツールです。

> 🚧 開発中です。下の「機能」は、これから実装する予定のものを含みます。

## なぜ作ったか

ブログ記事を書くとき、下書きはメモ帳で書き、WordPressに移すときに見出しタグを1つずつつけ直していました。この作業は記事のたびに発生し、つけ忘れや見出しレベルの間違いも起きやすいものでした。

memo-press は、普段どおりに書いた下書きを貼るだけで、見出しタグを自動でつけ、読みにくい文や表記ゆれも指摘します。

## 機能

### 変換

記法を覚えなくても、普段の書き方のまま変換できるようにしています。

| 下書き | 変換後 |
|---|---|
| 「。」で終わらない行 | `<h2>…</h2>` |
| 先頭に `h3` をつけた行 | `<h3>…</h3>` |
| 構成メモ用の区切り（「書き出し＆問題定義」「解決策＆詳細説明」「〆」） | 削除 |
| それ以外の行 | そのまま（クラシックエディタが空行を段落に変換するため、`<p>` はつけない） |

変換例：

```text
3:4(2K)を選んでおけば間違いない
いろいろ試したけどこのサイズが1番ちょうどよかったです。

h3 手順1 アイビスを開く
マイギャラリーを押します。
```

```html
<h2>3:4(2K)を選んでおけば間違いない</h2>
いろいろ試したけどこのサイズが1番ちょうどよかったです。

<h3>手順1 アイビスを開く</h3>
マイギャラリーを押します。
```

### チェック

- 見出しの判定ミスの疑い（「。」の書き忘れで本文が見出しになっている、など）
- 長すぎる文
- 同じ語尾の連続（「〜です。」が続く、など）。あわせて、2文をつなげる・語尾を変えるといった書き直しの例を出す
- 表記ゆれ（「出来る」と「できる」の混在、など）

指摘をクリックすると、下書きの該当行がハイライトされます。

### その他

- プレビューで見出しを色分けして表示する
- HTMLをワンクリックでコピーする
- 下書きをブラウザに自動保存し、テキストファイルとして書き出す
- 下書きをワンクリックで削除する（続けて別の記事を変換するとき用。削除した直後なら元に戻せる）

## 特徴

- **サーバー不要・無料**: すべての処理がブラウザの中で完結します。入力した文章が外部に送られることはありません。
- **変換とチェックで処理を共有**: 下書きを「行の種類（見出し・本文・削除）の並び」という中間データにしてから、HTMLの出力とチェックの両方に使います。

## ローカルでの起動

Node.js が必要です。

```bash
git clone https://github.com/marinnk/memo-press.git
cd memo-press
npm install
npm run dev
```

ターミナルに表示されたURL（通常は http://localhost:5173 ）をブラウザで開いてください。
